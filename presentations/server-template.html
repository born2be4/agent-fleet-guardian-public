Shareable template

Personal Hermes Agent Server

Обезличенный шаблон для коллег: роли агентов, автозапуск, память, безопасность, миграция и проверка без приватных данных.

Что собираем

Host
Mac mini, laptop, VPS or mini PC
Runtime
Hermes profiles
Autostart
launchd or systemd
Security
No secrets in Git

Базовые профили

ProfilePurpose
infraРемонт, деплой, диагностика, серверные операции.
commsКоммуникации, статусы, согласования, резюме.
analyticsОтчеты, таблицы, метрики, проверка чисел.
contentПосты, PR, каналы, медиа и артефакты.

Правила безопасности

Секреты остаются локально. В Git идут только шаблоны, инструкции, обезличенные runbooks и проверочные скрипты. Перед публикацией запускается scripts/sanitize-scan.sh.

Как стартовать

StepAction
1Создать директории через scripts/bootstrap-macos.sh.
2Установить Hermes по официальной инструкции.
3Скопировать профиль из examples/profiles.
4Подключить launchd/systemd.
5Проверить healthcheck и live smoke.
